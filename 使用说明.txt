========================================================
  CAN 报文解析工具 V1.0  使用说明
  适用: GB/T 27930 充电协议 / GB/T 18487.4 直流V2L放电协议
========================================================

【怎么用】
  1. 双击  CAN报文解析工具.exe
  2. 点"添加文件…", 选择 CAN 分析仪导出的 CSV 抓包文件 (可多选、批量)
  3. 点"开始解析并导出 Excel"
  4. 解析结果自动保存在原 CSV 同目录, 文件名后加 "-解析.xlsx"

  例:  C:\...\20260807-163654.csv
    → C:\...\20260807-163654-解析.xlsx

【生成的 Excel 内容】
  工作表1 "报文解析"  —— 逐帧翻译, 带颜色区分收发方向
       蓝色字 = 车辆(BMS) → 设备
       橙色字 = 设备 → 车辆(BMS)
       红色字 = 未识别的 CAN ID
       列: 序号 / 时间(s) / 与上一帧间隔Δt(ms) / 方向 / CAN ID /
           报文代号 / 数据HEX / 字段级解析
       表头已冻结并启用筛选, 可按"报文"列筛选只看某一种报文。

  工作表2 "关键事件时间线" —— 每种报文首次出现的时刻, 一眼看清握手流程顺序

  工作表3 "报文统计" —— 每种报文的帧数, 以及平均/最小/最大发送间隔
       (可用来检查周期是否正常, 例如 CCS 应为 50ms、ERD/BDC 应为 250ms)

【支持解析的报文】
  27930 充电: CHM BHM CRM BRM BCP CTS CML BRO CRO BCL BCS BSM
              BST CST BSD CSD BEM CEM  (含 BRM/BCP/BCS 多包传输)
  18487.4 放电新增: BDR ERD BDC BDST EDST ESD  (含 BDR/ERD 多包传输)
  传输协议: TP.CM 的 RTS / CTS / EndACK / Conn_Abort 与 TP.DT 数据包,
            自动跟踪会话所属报文, 逐包解出字段含义。

【选项说明】
  "车辆端名称 / 设备端名称" —— 只影响 Excel 里"方向"列的显示文字。
        例如台架测试可改成 "取电器(车端)" 和 "放电设备"。
  "完成后自动打开解析结果" —— 勾选则解析完直接弹出 Excel。

【CSV 格式要求】
  只要表头里含有 "帧ID" 和 "帧数据" 两列即可 (常见 CAN 分析仪导出格式)。
  程序会自动识别文件编码(GBK/UTF-8)和列位置, 时间列可有可无。

【常见问题】
  Q: 提示"原文件被占用, 另存为 xxx-解析(新).xlsx"
  A: 上次生成的 Excel 还在打开着, 关掉 Excel 再解析即可。

  Q: 某些帧显示"未在协议表中的CAN ID"
  A: 该 ID 不属于两个国标定义的报文(可能是其他设备或私有报文), 属正常。

【发给别人使用】
  只需发 CAN报文解析工具.exe 一个文件即可, 对方电脑不需要装 Python。
  运行要求: 64位 Windows 10 或更高版本。(32位系统、Win7/8 不支持)

  对方第一次运行可能遇到两种拦截, 都属正常, 处理方法:

  1) 蓝色窗口"Windows 已保护你的电脑"
     → 点左侧"更多信息" → 点"仍要运行"
     原因: 本程序没有购买代码签名证书, 属于未签名程序。

  2) 杀毒软件(360/火绒/Windows Defender 等)报毒或直接删除
     → 在杀毒软件里选择"信任/加入白名单/恢复文件"
     原因: 用 PyInstaller 打包的程序常被误报, 属于已知的误杀,
           不是真的病毒。如果对方不放心, 可以把 CAN报文解析工具.py
           源码一起发过去, 内容完全公开可审查。

  提示: 首次启动约需 3~10 秒(程序要把自身解压到临时目录), 之后会快一些。

【源码与二次开发】
  CAN报文解析工具.py 是完整源码 (Python), 需要 Python 3.8+ 和 openpyxl。
  改协议表: 修改文件开头的 ID_MAP (CAN ID → 报文名+方向) 和
            Decoder.decode() 里的字段解析即可。
  改完可用 启动工具.bat 直接运行源码版, 无需重新打包 exe。

  重新打包 exe 的命令:
    python -m PyInstaller --onefile --windowed --name "CAN报文解析工具" ^
           --hidden-import openpyxl "CAN报文解析工具.py"
