# CAN 报文解析工具

把 CAN 分析仪导出的 CSV 抓包文件，一键解析成**逐帧翻译、按收发方向着色**的 Excel 文件。

支持两个国标充放电通信协议：

- **GB/T 27930** 非车载充电机与电动汽车之间的数字通信协议（直流充电）
- **GB/T 18487.4** 电动汽车传导充放电系统 第 4 部分：车辆对外放电要求（直流 V2L 放电，附录 D）

## 功能

- **逐帧字段级解析**：不只是显示原始 HEX，而是翻译成「最高允许放电电流 +50.0A，最低允许放电电压 200.0V，最低允许 SOC=5%」这样的可读内容
- **多包传输（J1939 TP）会话跟踪**：自动关联 RTS / CTS / DT / EndACK，识别每个数据包属于哪条报文（BRM、BCP、BCS、BDR、ERD 等）
- **收发方向着色**：车辆端发出的报文为蓝色，设备端发出的为橙色，一眼区分通信方向
- **周期统计**：每种报文的帧数与平均 / 最小 / 最大发送间隔，可快速发现周期异常、报文丢失等问题
- **关键事件时间线**：每种报文首次出现的时刻，用于核对握手流程顺序
- 批量导入、自动识别文件编码（GBK / UTF-8）与列位置

## 生成内容

| 工作表 | 内容 |
| --- | --- |
| 报文解析 | 逐帧翻译，含序号 / 时间 / 帧间隔 / 方向 / CAN ID / 报文代号 / 数据 HEX / 字段解析，表头冻结并启用筛选 |
| 关键事件时间线 | 每种报文首次出现的时刻与抓包序号 |
| 报文统计 | 每种报文的帧数与平均 / 最小 / 最大间隔 |

## 使用方法

1. 运行程序（`CAN报文解析工具.exe`，或用 Python 运行源码）
2. 点「添加文件…」，选择 CAN 分析仪导出的 CSV（支持多选批量）
3. 点「开始解析并导出 Excel」

解析结果保存在原 CSV 同目录，文件名后加 `-解析.xlsx`。若该目录不可写（例如直接从压缩包或只读网络盘打开），会自动改存到桌面。

界面上的「车辆端名称 / 设备端名称」只影响 Excel 中方向列的显示文字，可按实际场景填写。

## CSV 格式要求

表头中包含 **帧ID** 与 **帧数据** 两列即可（常见 CAN 分析仪导出格式均满足）。程序会自动识别：

- 文件编码：GBK / UTF-8 / UTF-8 BOM
- 列位置：帧ID、帧数据、时间列（时间列可缺省）
- 时间格式：`2695.973.722`（秒.毫秒.微秒）、`16:36:54.123`（时:分:秒）、普通浮点秒

## 支持解析的报文

**GB/T 27930 充电**：CHM、BHM、CRM、BRM、BCP、CTS、CML、BRO、CRO、BCL、BCS、BSM、BST、CST、BSD、CSD、BEM、CEM

**GB/T 18487.4 放电新增**：BDR、ERD、BDC、BDST、EDST、ESD

**传输协议**：TP.CM 的 RTS / CTS / EndACK / Conn_Abort，以及 TP.DT 数据包

## 从源码运行

```bash
pip install openpyxl
python CAN报文解析工具.py
```

需要 Python 3.8+。界面使用 Python 自带的 tkinter，唯一的第三方依赖是 `openpyxl`。

## 打包为独立 exe

```bash
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name "CAN报文解析工具" --hidden-import openpyxl "CAN报文解析工具.py"
```

打包后的 exe 自包含，目标电脑无需安装 Python，运行要求为 **64 位 Windows 10 或更高版本**。

由于未购买代码签名证书，首次运行可能出现 SmartScreen 提示（点「更多信息」→「仍要运行」），部分杀毒软件也可能误报 PyInstaller 打包程序，需加入白名单。

## 扩展其他协议

协议定义集中在源码开头，添加新报文只需改两处：

- `ID_MAP`：CAN ID → (报文代号, 方向)，方向 `V` 为车辆端发出、`D` 为设备端发出
- `Decoder.decode()`：报文的字段解析逻辑

## 开发笔记

使用 openpyxl 处理大文件时有两个性能陷阱，本项目已规避：

- `ws.max_row` 与 `ws.max_column` 都会**全表扫描**，而 `ws[行号]` 内部会调用 `max_column`。在逐行循环里使用它们会退化为 O(n²)——5 万帧导出需要 288 秒。改为自行维护行号并用 `ws.cell(row=, column=)` 定位后降至 14 秒。
- 样式对象需预先创建复用，不能为每个单元格新建 `Font` / `PatternFill`。
